About

I work in the Java Platform Group at Oracle, advancing the Java programming language in OpenJDK through language design, the JDK Enhancement Proposal (JEP) process, javac implementation, and authorship of the Java Language Specification (JLS). My current work focuses on pattern matching and broader language evolution under Project Amber.

Previously, I worked on the Scala 3 compiler as a postdoctoral researcher at EPFL with Martin Odersky. I earned my PhD at the University of Athens under Yannis Smaragdakis, where my research focused on programming languages and high-performance stream processing, with publications at POPL, OOPSLA, and ECOOP.

Elected JDK Committer in 2023 and JDK Project Reviewer in 2024.

Java & talks

I contribute to Java language evolution alongside colleagues in Oracle’s Java Platform Group and the wider OpenJDK community. My contributions span delivered features, preview features, draft proposals, and compiler prototypes.

  • Unnamed Variables & PatternsJEP Owner: specified and implemented the feature from preview in JDK 21 (JEP 443) to final delivery in JDK 22 (JEP 456).
  • Primitive Types in Patterns, instanceof, and switchJEP Owner: specified and implemented the feature across five previews in JDK 23–27: 455, 488, 507, 530, and 532. Preview feature.
  • Enhanced Local Variable DeclarationsJEP Owner: developed the draft proposal and the proposed compiler implementation.
  • Research Prototype: DeconstructorsCo-authored and prototyped the translation and reflection for deconstructors.
